# 雨生编辑器（Flora Editor）操作手册

## 一、安装与启动

### 1.1 桌面版（推荐）

双击项目根目录的 **`雨生编辑器.exe`** 即可启动。程序会自动：
1. 在后台拉起 Flask 服务（Sidecar 子进程）；
2. 等待服务健康检查通过；
3. 打开编辑器主窗口。

> 关闭主窗口时后台服务进程会一并退出，无需手动清理。

### 1.2 开发模式（浏览器）

```bash
cd server
python app.py
# 浏览器访问 http://127.0.0.1:5000
```

### 1.3 云端演示（CloudStudio）

```bash
sh start.sh    # 自动安装依赖并以 0.0.0.0:8000 启动
```

CloudStudio 会自动检测 8000 端口并生成公开访问链接。

## 二、首次配置（必做）

首次启动会弹出**新手引导对话框**，按提示完成：

1. **填写 API Key**：在工作台顶部的「API Key」输入框粘贴你购买的模型密钥（支持 DeepSeek、通义千问、智谱 GLM、Kimi 等 8 家厂商）。
   > Key 仅在本次会话内存中使用，不保存到磁盘；每次启动需重新输入，属安全设计。
2. **选择模型**：下拉选择与 Key 匹配的模型（如 `deepseek-chat`）。
3. **（可选）高级参数**：点击「高级参数」可调整温度、最大长度等生成参数。

## 三、主界面与四大页签

主界面顶部为导航栏，共 4 个页签：**工作台 / 模板管理 / 文风管理 / 生成记录**。

### 3.1 工作台（生成文章）

**操作流程：**

1. **填写标题与正文要求**：在工作台左侧输入文章标题和写作要求。
2. **启用模板**：在模板面板勾选需要的提示词模板（可多选叠加），系统将自动合并。
3. **填写变量**：若模板含 `{{变量}}` 占位符，按提示填入实际值。
4. **设置生成选项**：
   - ✅ **去 AI 味**：生成后自动消除机械感（推荐开启）；
   - ✅ **文风参考**：启用 Style Card / 语料库注入（需先在「文风管理」配置）。
5. **点击「预览提示词」**（可选）：查看最终组装的完整提示词，确认无误。
6. **点击「生成」**：右侧开始流式输出。界面会依次显示六个阶段的进度：组装提示词 → 初稿 → RAG 检索 → 风格重写 → 去 AI 味 → 完成。
7. **结果编辑**：生成完成后可在结果编辑面板直接修改文字；满意后保存，自动归档到「生成记录」。

> 同一时刻只允许一条生成任务进行中（并发互斥保护），等待完成或取消后再发起新任务。

### 3.2 模板管理

| 操作 | 步骤 |
|------|------|
| 新建模板 | 「模板管理」→「新建」→ 填写名称、分类、内容（支持 `{{变量}}`）→ 保存 |
| 编辑模板 | 选中模板 → 编辑 → 保存（**旧版本自动留档，可随时回滚**） |
| 查看版本 | 模板详情 →「版本历史」→ 查看历次修改 |
| 回滚版本 | 版本历史中选择目标版本 →「恢复」 |
| 启用/停用 | 模板列表中的开关切换（停用后不参与生成） |
| 导入/导出 | 「导出」打包 JSON 分享给他人；「导入」载入他人模板 |
| 入门模板 | 首次使用可点「载入入门模板」，一键获得预置模板集 |

### 3.3 文风管理

文风管理包含两张卡片：

**① Style Card（文风卡）**

1. 选择一个模板，上传或粘贴一篇能代表你文风的**范例文章**；
2. 点击「分析」——系统在**本地**分析 44 项文风特征（句长节奏、标点习惯、对话密度、意象偏好等），生成文风卡；
3. 分析完成后，工作台开启「文风参考」即自动注入生成链路；
4. 范例文章修改后，系统通过哈希检测提示「已过期」，点击「刷新」重新分析。

**② 文风语料库（Style RAG）**

1. 「文风管理」→「新建语料库」，起名（如"我的小说稿"）；
2. 「导入」粘贴或上传你过往的作品文本（建议 ≥ 数千字）；
3. 点击「建立索引」——系统自动分句切块并本地向量化，进度条实时可见；
   > 首次建索引会下载本地 Embedding 模型（一次性），之后完全离线、零 API 成本。
4. 索引完成后，生成时自动混合检索最相关的 4 个片段注入提示词，让 AI 模仿你的表达方式。

**③ 文风范例片段**：Style Card 分析产生的范例片段可逐条编辑（场景、视角、情感、节奏标签）、启停或置顶，精细控制注入内容。

### 3.4 生成记录

1. 每次生成自动归档，列表按时间倒序，支持分页、搜索；
2. 点击一条记录进入详情，可查看**四个版本对比**：
   - 初稿（LLM 原始输出）
   - 去 AI 味版
   - 风格重写版
   - 人工编辑版（最终稿）
3. 侧栏「原文 / AI 修改后」对比视图中，可直接在右侧编辑并采纳修改；
4. 支持为记录打**评分（1~5 星）**、加**笔记**、**置顶**；
5. 删除支持单条与批量。

## 四、典型工作流（端到端示例）

**目标：用个人文风生成一章小说。**

```
① 模板管理：新建「玄幻章节」模板，写清结构要求，启用
② 文风管理：上传 2 万字旧稿建语料库索引（一次性）
③ 工作台：填标题+本章大纲 → 启用模板 → 开启去AI味+文风参考
④ 点击生成：观看六阶段流水线流式输出
⑤ 结果编辑：微调措辞 → 保存
⑥ 生成记录：四版本对比，确认风格重写版效果 → 5 星评分
⑦ 迭代：满意段落的写法沉淀为新模板 → 回到 ③
```

## 五、常见问题（FAQ）

| 问题 | 处理方法 |
|------|---------|
| 提示"API Key 无效" | 确认 Key 与所选模型厂商匹配；Key 前后无空格；账户有余额 |
| 生成中界面卡住 | 检查网络；SSE 连接中断可直接取消后重试，已完成阶段的结果会保留在记录中 |
| 文风参考开关灰色 | 先到「文风管理」完成 Style Card 分析或语料库索引 |
| 索引进度长时间不动 | 首次需下载本地 Embedding 模型，取决于网速；可在「Embedding 模型状态」查看进度 |
| 想找回旧版模板 | 模板详情 →「版本历史」→ 选择版本恢复 |
| 数据存在哪里 | 全部在本机 `data/*.db`（SQLite），可随时备份该文件 |
| 换电脑怎么迁移 | 备份 `data/` 目录 + 在新机导出的模板 JSON 一并导入 |

## 六、数据与安全须知

- 所有文章、模板、语料、记录**仅存于本机**，不上传任何服务器；
- API Key 不落盘、不写日志，关闭程序即失效；
- 备份 = 复制 `data/` 目录；彻底删除 = 删除 `data/` 目录。
